# Homework 28.03.2026

## Описание
Это программа для анализа лог-файлов. Она находит записи с уровнем WARN, ERROR и SEVERE. Для поиска используется Pattern и Matcher. Логика фильтрации вынесена в отдельный класс LogFilter. Метод filter принимает список строк и возвращает только те, которые подходят под критерий.

## Запуск
Перед тестированием создайте файл example.log в корне проекта.
